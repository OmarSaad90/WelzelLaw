# Welzel Law — Project Instructions

Before doing anything in this project, always read:
- `design.md` — full design system, color tokens, typography, motion, layout principles
- `product.md` — product context, brand tone, users, anti-patterns
- `src/tokens.css` — CSS custom properties
- `src/tokens.ts` — JS/TS design tokens

## Non-negotiables
- Never use hard section dividers or border lines between sections
- Never use stock imagery of gavels, scales of justice, or courtrooms
- Always use tokens from tokens.css — never hardcode colors or font sizes
- All animations use Framer Motion with expo-out easing
- Asymmetric layouts — avoid identical card grids
- The site must feel premium and expensive to visit
